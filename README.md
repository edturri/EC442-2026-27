## Running the notebooks online

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/edturri/EC442-2026-27?quickstart=1)

You can run the notebooks in your browser with GitHub Codespaces, without installing anything:

1. Sign in to GitHub and click the button above, then **Create codespace**. The first start takes a few minutes, while Python and the required packages are installed.
2. The notebook opens automatically. Click **Run All**, and if you are asked to select a kernel, choose **Python Environments** and then **Python 3.12**.
3. When you are done, stop the codespace from [github.com/codespaces](https://github.com/codespaces). It also stops by itself after 30 minutes of inactivity.

Personal GitHub accounts include a free monthly allowance of Codespaces usage, which is more than enough for these notebooks.
